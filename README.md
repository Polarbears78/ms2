# 과학 단원 평가 웹앱

중학교 과학 단원을 선택하면 해당 단원의 평가를 **한 문제씩** 풀고, 제출 즉시 **정답 피드백과 해설**을 받는 학습용 웹 애플리케이션입니다.

## 화면 흐름

1. **단원 선택** — Ⅰ~Ⅳ 단원 카드 중 선택 (현재 Ⅲ. 빛과 파동만 평가 제공)
2. **평가 목록** — 선택한 단원 아래의 평가 목록 (`Ⅲ. 빛과 파동 — 총괄 평가 1회`)
3. **문제 풀이** — 한 문제씩 풀이
   - 객관식: 보기를 누르면 즉시 정답/오답 채점 + 해설
   - 복수 정답: 정답 개수만큼 선택하면 채점
   - 단답형(3번): 정답 입력 후 채점
   - 서술형(17~20번): 답 작성 후 **모범 답안**과 비교(자기 평가)
4. **결과** — 점수, 문항별 채점표, 다시 풀기

## 평가 내용 (Ⅲ. 빛과 파동 · 총괄 평가 1회)

- 총 20문항 (객관식 16 · 단답형 1 · 서술형 4, 9번은 복수 정답)
- 교과서 97~138쪽 범위
- 정답은 제공된 PDF 정답지를 기준으로 입력되어 있습니다.

> 그림이 있는 16개 문항은 PDF에서 추출한 실제 그림(`assets/figures/`)을 표시합니다.
> 1번은 보기 자체가 그림(정답 노출 방지로 미표시), 6·12·14번은 그림이 없는 문항입니다.

## 그림 추가/교체 방법

각 문제는 `data.js`에서 `image` 필드로 그림을 연결합니다.

```js
{
  id: 9,
  topic: "렌즈에 의한 상의 특징",
  type: "multi",
  stem: "...",
  image: "assets/figures/q09_lens_zebra.png", // ← 그림 파일 경로
  figureNote: "(가)는 오목 렌즈, (나)는 볼록 렌즈로 ...", // 그림 아래 캡션(선택)
  ...
}
```

- 그림 파일을 `assets/figures/` 폴더에 넣고, 해당 문항에 `image: "assets/figures/파일명.png"` 한 줄을 추가하면 됩니다.
- `image`가 없으면 `figureNote`가 안내 문구 박스로 표시되고, 둘 다 없으면 그림 영역이 생략됩니다.
- 현재 그림들은 제공된 PDF에 임베디드된 원본 이미지를 추출해 사용했습니다.

## 활동지 생성기 · 평가기록 (`worksheet.html`)

단원을 고르면 활동지를 화면에서 만들고, 인쇄(PDF)하거나 학생 응답을 기기에 기록할 수 있습니다.

### Ⅴ. 식물과 에너지 — 2. 식물의 호흡과 광합성산물

| 항목 | 내용 |
|------|------|
| 차시 | 01 식물의 호흡과 광합성의 관계 (1/3차시) |
| 교과서 | 188~191쪽 |
| 학습 목표 | 호흡과 광합성 과정에서 출입하는 에너지와 물질의 변화를 분석할 수 있다. |
| 준비물 | 교과서, 개념 정리 활동지, 해 보기 활동지 |

활동지 4종을 제공합니다.

- **개념 정리 활동지** (12문항) — 호흡·광합성의 물질/에너지 출입, 빛 조건별 겉보기 기체 출입, 광합성 산물의 전환·이동·저장
- **해 보기 활동지** (9문항) — BTB 용액·검정말 탐구의 변인 설정과 대조군, 오차 요인, 하루 CO₂ 농도 자료 해석, 안전 수칙, 정보 그림 표현
- **총괄 평가** (10문항) — 스스로 확인하기용 단답 문항
- **서술형 평가** (5문항) — 겉보기 결과와 실제 과정의 구분, 물질의 용해성과 이동, 정량 비교를 요구하는 판단 문항

교사용 토글을 켜면 정답·모범 답안과 함께 **오개념·지도 유의점**이 문항별로 표시됩니다.

### 평가기록

| 기능 | 설명 |
|------|------|
| 응답 기록 모드 | 학급·번호·이름과 문항별 응답을 입력하면 `localStorage`에 자동 저장(디바운스 0.6초). 외부 전송 없음 |
| 교사용 채점표 | 학습 목표를 준거로 한 평가 요소 5종 × 3수준(상·중·하) 루브릭 |
| 관찰 사실 기록 | 과정 중심 평가용 관찰 기록란. 관찰한 행동·발언·산출물만 사실대로 기록 |
| 내보내기 | 응답 요약 복사, CSV 내려받기(UTF-8 BOM), 인쇄/PDF |

> 기록은 브라우저(기기)에만 저장되므로 기기·브라우저를 바꾸거나 방문 기록을 지우면 남지 않습니다.
> 보관이 필요하면 CSV 또는 PDF로 산출물을 확보하십시오.
>
> 성취기준 코드·배점·반영 비율은 학교 학업성적관리규정과 평가 계획에 맞추어 조정해야 하며,
> 성취 수준의 최종 판정과 학교생활기록부 기재 여부는 교사의 전문적 검토로 결정합니다.

## 실행 방법

별도 빌드가 필요 없는 정적 웹앱입니다.

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저에서 바로 열어도 됩니다.
