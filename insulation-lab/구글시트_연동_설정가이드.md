# 보온 컵 설계 탐구 — 구글 시트 연동 설정 가이드

학생들이 ‘📊 구글 시트로 제출’을 누르면, 각 조의 보고서가 **선생님의 구글 시트에 한 줄씩** 자동으로 쌓이도록 하는 설정입니다. 한 번만 해 두면 됩니다. (약 5분)

---

## 1단계 — 구글 시트 만들기
1. https://sheets.google.com 에서 **빈 스프레드시트** 하나를 만듭니다.
2. 이름을 알아보기 쉽게 바꿉니다. (예: `보온컵 탐구 제출`)

## 2단계 — Apps Script 붙여넣기
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본으로 들어 있는 코드를 모두 지우고, 같은 폴더의 **`APPS_SCRIPT.gs`** 내용을 전부 붙여넣습니다.
3. 💾 (저장) 을 누릅니다.

## 3단계 — 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 선택합니다.
3. 설정:
   - **실행 대상**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포** 를 누르고, 권한 승인을 요청하면 본인 구글 계정으로 허용합니다.
5. 배포가 끝나면 나오는 **웹 앱 URL** 을 복사합니다.
   - 형식: `https://script.google.com/macros/s/AKfy............/exec`

## 4단계 — 보고서에 주소 연결
1. `index.html` 을 열어 위쪽 스크립트의 다음 줄을 찾습니다.
   ```js
   var SHEET_ENDPOINT = "";
   ```
2. 따옴표 안에 3단계에서 복사한 URL 을 붙여넣고 저장합니다.
   ```js
   var SHEET_ENDPOINT = "https://script.google.com/macros/s/AKfy............/exec";
   ```
3. 변경한 `index.html` 을 저장소에 커밋/푸시하면(또는 다시 업로드하면) 적용됩니다.

---

## 확인 방법
- 학생 화면에서 아무 조나 골라 온도를 몇 개 입력한 뒤 **‘구글 시트로 제출’** 을 눌러 봅니다.
- 시트에 **`보온컵제출`** 이라는 탭이 자동으로 생기고, 첫 줄에 제목(헤더), 그 아래에 제출 내용이 기록되면 성공입니다.

## 기록되는 열(순서)
`submittedAt`(제출시각) · `jo`(조) · `designConduction`(전도 차단) · `designConvection`(대류·증발 차단) · `designRadiation`(복사 차단) · `layout`(재료 배치) · `predictDelta`(예측 ΔT) · `predictReason`(예측 이유) · `t0~t15`(0·3·6·9·12·15분 온도) · `startTemp`(시작 온도) · `endTemp`(마지막 온도) · `deltaT`(온도 하강폭) · `bestFactor`(잘 막은 요인) · `predVsResult`(예측 vs 결과) · `redesign`(재설계)

## 자주 묻는 것
- **개인정보**: 이름·학번은 받지 않습니다. ‘조 번호’만 기록됩니다.
- **여러 번 제출**: 누를 때마다 새 줄로 쌓입니다. 최신 것이 가장 아래 줄입니다.
- **CORS 오류처럼 보일 때**: 코드가 `text/plain` + `no-cors` 방식으로 보내므로 대개 정상 기록됩니다. 제출 후 시트를 새로고침해 확인하세요.
- **재배포**: 코드를 수정하면 **배포 → 배포 관리 → 편집(연필) → 새 버전 → 배포** 로 갱신합니다. URL 은 그대로 유지됩니다.
